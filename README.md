\# Proyecto Integrador Móviles G7



Aplicación móvil desarrollada como proyecto integrador para el proceso de formación en desarrollo de aplicaciones móviles.



\## Descripción



Este repositorio contiene el código fuente, configuración y recursos correspondientes al Proyecto Integrador Móviles G7.



El proyecto será desarrollado de forma colaborativa aplicando buenas prácticas de control de versiones mediante Git y GitHub.



\## Tecnologías



\- Android Studio

\- Kotlin

\- Gradle

\- Jetpack Compose

\- Git

\- GitHub



\## Requisitos



Para ejecutar el proyecto se recomienda disponer de:



\- Android Studio actualizado.

\- JDK compatible con la versión de Gradle utilizada.

\- Android SDK.

\- Git.

\- Sistema operativo Windows.
